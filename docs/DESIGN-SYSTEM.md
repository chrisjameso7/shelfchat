# Design system — core reader pass

Canvas #0A0A0A, surfaces #111012/#17141C, warm text #E9E6DF, lavender #BCA4F5, muted text #AAA4B3 and subtle neutral borders. Tokens live in src/styles.css. Interface text remains Arial/Helvetica; editorial headings use Georgia with local fallbacks, avoiding a font service or another download. Heading sizes are fluid; body copy is 14–15px with generous line height. Spacing tokens use a 4px base. Buttons and navigation have 44px minimum targets.

Library, detail, community, contribution status, dialogs and policy pages use the same neutral surface/focus/button rules. Large surfaces are matte, without mandatory backdrop filters. Mood chips retain restrained distinct colors. Original source covers load lazily where supplied, with no-referrer requests and an editorial typography fallback when absent or failed. These are not represented as verified original edition covers.

Mobile navigation stays visible. Search controls wrap at tablet widths; cards use constrained proportions and break long titles. Composer text is not cleared on a failed request. Native dialogs trap focus, accept Escape and have labelled close controls. Reduced-motion/transparency preferences are retained.

Collection options and category chips come from populated public records; mood rules remain deterministic subject associations, not personalization. Search defaults to relevance with an exact-title bonus while retaining explicit alphabetical/download/recent sorts. Source-rights assertions are labelled without claiming universal legal status. Community has no follower or like counts. The reading-room count is approximate recent presence rather than verified people.
